# @libo11y/rum

libo11y RUM for browsers and MV3 extensions, built on
[`@libo11y/web`](https://github.com/jamesainslie/libo11y/tree/main/ts/packages/web).

```sh
npm install @libo11y/rum
```

## Status

The package is in development and is not on npm yet. The collectors arrive
in later commits of this release.
