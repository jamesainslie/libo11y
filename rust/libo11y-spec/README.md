# libo11y-spec

The libo11y telemetry specification for Rust: the attribute keys, closed
enums, event and metric names, and the sensitivity and contract tables of
the [libo11y specification](https://github.com/jamesainslie/libo11y/blob/main/docs/SPEC.md).

The crate is generated by specgen from `spec/registry` in the libo11y
repository, the same source as the Go `spec` package and the TypeScript
`@libo11y/spec` package. Do not edit `src/generated/` by hand: change the
registry and run `make spec-generate`.

```rust
use libo11y_spec::{Outcome, Sensitivity, attr, sensitivity_of};

assert_eq!(attr::OUTCOME, "o11y.outcome");
assert_eq!("success".parse::<Outcome>(), Ok(Outcome::Success));
assert_eq!(sensitivity_of("host.ip"), Some(Sensitivity::Pii));
```

The crate has no dependencies. Its minimum supported Rust version is 1.88.
